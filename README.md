# login - Tela de login

### Descrição

Projeto criado na aula de programação front-end, na Unicesumar, campus de Londrina. O professor [Leonardo Rocha](htts://github.com/leonardossrocha) introduziu os conceitos de framework, apresentando o Bootstrap e alguns exemplos disponíveis nesse framework, além do uso do Git, realizando o passo a passo de configuração do ambiente de desenvolvimento.

Durante o desenvolvimento do projeto, foi adicionada uma seção de FAQ (Perguntas Frequentes), com o objetivo de organizar dúvidas comuns de forma estruturada e interativa, utilizando componentes do Bootstrap.

Também foi implementada uma imagem de perfil no projeto, aplicando conceitos de estilização com CSS, como alinhamento, tamanho, bordas e responsividade, contribuindo para um layout mais personalizado e visualmente agradável.

Além disso, o projeto proporcionou maior aprofundamento nos estudos de HTML e CSS, permitindo compreender melhor a estruturação semântica das páginas, organização de elementos, estilização, uso de classes, responsividade e boas práticas no desenvolvimento front-end.


### Ferramentas utilizadas

- HTML5
- CSS3
- Bootstrap
- Git
